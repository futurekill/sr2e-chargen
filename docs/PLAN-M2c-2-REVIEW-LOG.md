# Plan Review Log: M2c-2 (adept powers, S13)

## Round 1 — Codex gpt-6-sol high
- **Book limits:** [The plan](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-chargen/docs/PLAN-M2c-2.md:41) inherits `maxLevel: 6` for Pain Resistance and Improved Ability, but the [corrected printing](</Users/jcandalino/Code/foundryvtt/shadowrun/Shadowrun 2e - Shadowrun Second Edition (corrected 11th printing) {FASA7901}.pdf>) explicitly discusses 10 Pain Resistance points and gives noncombat Improved Ability no six-die cap. **Fix:** Remove those arbitrary pack limits and apply only the book’s Combat Skill cap and available Magic points.
- **Combat Sense has no effect:** The plan corrects its price and level limit, but [Combat Pool calculation](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/module/data/actor-data.mjs:1545) does not add the purchased dice. **Fix:** Add Combat Sense levels to Combat Pool during preparation and test the resulting pool.
- **Existing powers lack the new key:** Updating [pack JSON](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/packs-src/adept-powers/Combat_Sense_9d10344a9456397d.json:6) will not add `system.power` to embedded items in existing worlds, so the proposed fallback keeps pricing those core powers linearly. **Fix:** Migrate or identify existing core powers before applying the linear fallback to custom powers.
- **World totals can become illegal:** Repricing existing adepts can raise Used above Magic; a release note alone leaves no rule for resolving that state. **Fix:** Test representative existing actors, report any overage without deleting powers, and document the player or GM choice required to surrender full improvement points.
- **Derived values can linger:** [CharacterData](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/module/data/actor-data.mjs:587) currently sets Used and Max only for physical adepts; a changed magic type can retain the prior values, and a schema `cost` default of zero would mask a `?? totalCost` fallback. **Fix:** Reset both totals and every per-item derived cost on every preparation, using an ephemeral cost value rather than a persisted zero-default field.
- **Two displays still read `totalCost`:** The plan names the actor Cost column but misses the [item sheet](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/templates/item/item-body.hbs:1181) and [chat power card](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/module/documents/item.mjs:434). **Fix:** Route all three displays through the same prepared cost.
- **Improved Ability’s target will not apply:** The app plans to store a skill *ID*, while [the system lookup](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/module/data/actor-data.mjs:714) matches `improvedSkill` to a skill *name*; `category: active` also does not identify the book’s pricing row. **Fix:** Resolve the selected ID to its current skill name and explicit book area, and flag a target removed later.
- **Pack text conflicts with the proposed rules:** [Improved Ability](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/packs-src/adept-powers/Improved_Ability_7a4b0e85072ce4c6.json:10), [Pain Resistance](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/packs-src/adept-powers/Pain_Resistance_003f74fef4a1756e.json:17), and [Killing Hands (D)](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-foundryvtt/packs-src/adept-powers/Killing_Hands_D_30f5e3493545db6b.json:17) retain misleading limits or costs in descriptions or notes. **Fix:** Correct the human-readable pack data alongside the pricing code.
- **The app uses a pinned system copy:** [shared/rules.mjs](/Users/jcandalino/Code/foundryvtt/shadowrun/sr2e-chargen/shared/rules.mjs:9) neither exports `adeptPowerCost` nor reads the sibling checkout directly. **Fix:** Include the released system change in the content sync and export the helper from the pinned copy.
- **A simpler derived-cost path is available:** Adding `system.cost` creates another value whose default, clearing, and display behavior must be managed. **Fix:** Compute one actor-level per-power cost map each preparation and use it for Used, the sheet, and the chat card.

VERDICT: REVISE
