# Hoi chummer! — the SR2E character generator

A web app for building **Shadowrun, Second Edition** characters by the core book's rules, with page references for
every rule and item, printable sheets, and (later) export to the [SR2E Foundry VTT system](https://github.com/futurekill/sr2e-foundryvtt).
Built for a small private group: invite-only accounts, one container on your own server.

**Current release: v0.1.0-beta.1** (a pre-release). Character creation covers priorities, metatype, magic,
attributes, skills and resources (gear, cyberware, spells, foci), with full PDF sheets, a one-page table card, a
Markdown stat block and portraits.
